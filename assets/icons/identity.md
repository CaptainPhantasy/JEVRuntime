# JEVRuntime identity

An independent constitutional-supervision emblem: a protective architectural seal,
a central execution pillar, and balanced review pans. Slate and warm brass remain
legible on light and dark surfaces without a background plate.

The SVG and RGBA PNG exports have a fully transparent exterior. The ICO contains
16, 32 and 48 pixel images. `site.webmanifest` is supplied for web integrations;
JEVRuntime itself remains a terminal application and does not serve a web app.
Host launchers, particularly iOS, may composite transparent artwork onto a system
background. No maskable-purpose declaration is made for transparent artwork.
